UI style direction

Document-first
The contract is always the hero. Chrome is invisible. UI recedes, content leads.
Color as signal
Colors only appear when they mean something. No decorative fills. No brand washes.
Dense but calm
Tables and clause lists are information-dense. Generous line height keeps it readable.
No illustrations
This is a professional tool. No empty states with cartoon robots. Just clear copy.

Logo concept rationale — The mark is a document with a single red rule across the last line — a literal redline. The wordmark uses a red "i" as a subtle pointer: the product identifies what others miss. No shield, no magnifying glass, no legal scales. Just the document and the mark.
