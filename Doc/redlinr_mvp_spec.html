1 Core user workflow
1
Upload two contracts
Drag-drop or file picker. PDF or DOCX. Both files on one screen — no multi-step wizard.
2
Processing (10–30 sec)
Simple progress indicator. Extract text, chunk by clause, run AI diff. No queues, synchronous for MVP.
3
View the comparison report
Three-panel layout: left = original, right = redlined version, center = change summary list. Changes color-coded (added / removed / modified).
4
Review AI-flagged items
A prioritized list of "watch out" clauses (payment terms, liability caps, termination, auto-renewal). Each item links to the exact clause in the diff.
5
Export or share
One-click export to PDF summary or copy shareable link. Done. Sales Director sends to legal or uses in negotiation.
2 Must-have features (MVP only)
F1
Dual-file upload + text extraction
PDF & DOCX parsing. If text extraction fails, show a clear error — don't silently produce garbage output.
Foundational
F2
Clause-level diff (visual redline)
Side-by-side view with added/removed/changed text highlighted. Green = added, red = removed, yellow = modified. This is the core value prop.
Core value
F3
AI risk summary (5–8 flags)
Short-form flags on the highest-risk changes only: payment terms, liability, IP ownership, termination, auto-renewal, SLA penalties. Plain English, 1–2 sentences each.
Differentiator
F4
Change summary panel
Clickable list of all detected changes, grouped by section (Payment, Term, Liability, etc.). Clicking a change jumps to it in the diff view.
Navigation
F5
PDF export of comparison report
One-click export. Needed so users can forward to legal or attach to a deal thread. Minimum viable: just the summary + flagged items.
Shareability
F6
No-auth upload (magic link or session)
Don't gate behind signup for MVP. Let users try immediately. Capture email only if they want to save/share the report. Friction kills early adoption.

4 Simplest viable AI comparison
Rule-based (fast, free)
Text extraction → sentence tokenization → Myers diff algorithm for clause-level changes. No AI needed for the visual redline. Deterministic and fast.
AI layer (Claude / GPT-4o)
Send only the changed clauses to the LLM, not the full contract. Prompt: "identify which of these changes are material risks for the buyer." Keeps costs low, latency under 10s.
Acceptable accuracy for MVP
Misses some edge-case risk flags = acceptable. False positive risk flags = acceptable (user can dismiss). Misidentifies which text changed (wrong diff) = not acceptable — this breaks trust instantly. Prioritize diff accuracy over AI insight quality.
5 Technical shortcuts
→
No backend infra — use Vercel + serverless
Edge function handles upload + AI call. No servers to manage. Use Vercel Blob for temp file storage (auto-deleted after 24h).
→
PDF export = html-to-pdf (Puppeteer or React-PDF)
Don't build a custom PDF renderer. Use an existing library to snapshot the report view.
→
DOCX parsing = mammoth.js (client-side)
Run in the browser. Avoids server round-trip for extraction. Output is clean HTML, easy to diff.
→
Section classification = keyword heuristics first
Detect "Payment", "Liability", "Term" sections by header keyword matching before spending tokens on AI classification.
→
For scanned PDFs — fail gracefully
Show a clear "this PDF appears to be scanned — we can't process image-based PDFs yet." Don't promise OCR in week 1.
6 MVP success criteria
Quantitative signals
≥ 3 of 5 beta users finish a comparison without help

≥ 60% export or share the report

Time from upload → first flag reviewed < 3 min

At least 1 user says "I'd pay for this"
Qualitative signals
Users describe the flags as "useful" or "something I'd have missed"

Users forward the report to someone else unsolicited

Users return to try it on a second contract
Kill criteria: if users consistently say the diff is wrong or misleading, stop and fix the extraction pipeline before adding any AI features.
7 Biggest risks
High
Scanned / image PDFs
Most enterprise contracts are PDFs of scans. Text extraction returns nothing. Kills the demo. Mitigation: detect early, show clear error, add OCR (Tesseract) in week 2.
High
AI hallucinating risk flags
LLM invents a risk that doesn't exist. Sales Director acts on it, looks foolish to legal. Mitigation: always anchor each flag to a specific quoted clause. Never generate abstract risk statements.
Med
Poor clause segmentation
Contracts vary wildly in formatting. If you diff at the wrong granularity (word-level vs clause-level), the redline looks noisy and unusable. Mitigation: test on 10 real contracts before launch.
Med
User trust in AI output
Sales Directors may not trust or act on AI flags without legal backing. Mitigation: frame output as "things to ask your lawyer about" — not legal advice. Never use the word "legal analysis."
Low
Data confidentiality concern
Enterprise users won't upload real contracts to an unknown tool. Mitigation: add a "files are deleted within 1 hour" notice on the upload screen. Don't store contracts. Later: on-premise option.
